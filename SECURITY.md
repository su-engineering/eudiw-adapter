# Security policy

## Report a vulnerability

Email **[security@su.engineering](mailto:security@su.engineering)** privately. Do not open a public issue or pull request containing exploit details or live credentials.

Include the revision, the affected component and configuration, reproduction steps using synthetic credentials, and the observed impact.

Never send production private keys, access tokens, full real presentations, or personal credential data.

## Supported versions

No version has been released. Fixes land on `main`.
