# Test vector provenance

- `rfc9901/`: worked examples from RFC 9901 (SD-JWT), section 5.2 and Appendix A.1 to A.4, copied verbatim. Signed by the RFC authors with the key in Appendix A.5.
- `openid4vp/dcql-example-*.json`: DCQL queries from OpenID for Verifiable Presentations 1.0 (Final), section 7.4 and Appendix D.
- `openid4vp/section-8.3-response.txt`: the encrypted Authorization Response example from OpenID4VP 1.0 section 8.3, decryptable with the private JWK published in the same section.
- `status-list/appendix-c.json`: Appendix C test vectors from draft-ietf-oauth-status-list-14, with the listed indexes and values.

All are synthetic examples published in the specifications; none identify a real person or issuer.
